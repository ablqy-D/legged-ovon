# Results

> 每跑完一版加一行。**不覆盖、不删，失败的和作废的也留着。**
> 数字都走 [evaluation.md](evaluation.md) 的标准流程，不贴临时挑的指标。

## 命名规则

`v<序号>_<改动的核心>` —— 序号连续，改动用领域里已有的词。
**禁止** `test` / `final` / `final_v2` / `new` / 拿日期当名字。

## 版本表

| 版本 | 改了什么 | SR（主指标） | SPL | DTG | 结论 |
|---|---|---|---|---|---|
| v1 | Nav2 + Grounding DINO 基础链（baseline） | | | | 基准线 |
| v2 | Oracle（真值目标位姿/完美 grounding） | | | | 说明有多少可捞 |
| v3 | 随机/消融对照（去 grounding / 随机导航） | | | | 证明收益来自哪里 |

> v2 和 v3 别省。只有 baseline 和最终版的话，你不知道最终那个数算好还是不好。
