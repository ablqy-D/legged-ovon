# 复现

每个重要 baseline 一份复现报告，目录名用领域里已有的词，不用 `test` / `final` / 日期。

```
复现/<baseline 名>/
  ├── README.md        # 复现报告：环境、命令、结果、和论文数字的差异
  └──（可选）patch/ 配置/ 脚本
```

报告至少写清楚：

1. **复现的是什么**：论文 / 仓库 + 版本（commit）
2. **环境**：OS、ROS 版本、仿真版本、GPU
3. **跑的哪条命令**：从 clone 到出结果的完整步骤
4. **结果**：论文报的数 vs 自己跑出来的数
5. **差异解释**：差在哪、为什么、有没有可能是评测口径不同
6. **踩坑**：下次怎么绕过
